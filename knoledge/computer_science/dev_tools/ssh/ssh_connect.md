## CONEXIÓN A UN SERVIDOR

> [!abstract] SINTAXIS
> ssh ***\[userName\]***@***\[machin\]***

Cuando queramos cerrar la conexión usaremos el comando `exit`.

## EJECUCIÓN RÁPIDA

Si queremos ejecutar un único comando podemos seguir la siguiente sintaxis:

> [!abstract] SINTAXIS
> ssh ***\[userName\]***@***\[machin\]*** "***\[command\]***"

Este tipo de conexión no hace falta que la cerremos con el comando `exit` ya que se cierra automáticamente.
