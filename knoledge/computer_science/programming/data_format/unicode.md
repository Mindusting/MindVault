# UNICODE

> [!external-link]- REFERENCIAS WEB
> - [Unicode](https://home.unicode.org) #WWW/Unicode

Los ordenadores guardan el texto de forma de números, devido a esto, cada ordenador pordría identificar cada número a su manera, haciendo que la transferencia de texto de un ordenador a otro sea prácticamente imposible; para solucionar esto, se estableció el estandar **UNICODE**; este estandar en esencia es un alista enorme de números únicos (*es decir, que no se repien*) asociados cada uno a un carácter, símbolo o emoji; de esta forma todos los ordenadores interpretan los números que respresentan el texto de la misma forma.
