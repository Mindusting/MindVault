El estandar [**Unicode**](unicode.md) por sí solo, define que números representan que carácteres, pero no define como se deben almacenar estos números; aquí es donde entra el estandar **UTF** este define el algoritmo a seguir para guardar e interpretar *bytes* que representen códigos de [**Unicode**](unicode.md); este estandar viene en varios formatos: [**UTF-8**](#UTF-8), [**UTF-16**](#UTF-16) y [**UTF-32**](#UTF-32).
