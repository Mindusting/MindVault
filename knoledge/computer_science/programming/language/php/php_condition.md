Para usar los condicionales se usan tres *palabras clave*:

- `if`
- `elseif`
- `else`

> [!abstract] SINTAXIS
> 
> if (***\[condition\]***) {
> // code if true
> } elseif (***\[condition\]***) {
> // code if true in the second condition
> } else {
> // conde if false
> }
