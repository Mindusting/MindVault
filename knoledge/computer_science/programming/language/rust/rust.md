## DOCUMENTACIÓN LOCAL

Para poder leer la documentación local de **Rust** tendremos que ejecutar el siguiente comando en le terminal:

```bash
rustup doc
```

Este nos abrirá en el buscador de internet un archivo local; dentro de esta página podremos encontar un enlace con el nombre de "*The Rust Programming Language*", este está pensado para que lo lear los principiantes que quieren aprender **Rust**, por lo que es un buen sitio para empezar
