# GESTOR DE VERSIONES DE NODEJS

> [!fail]- ESTE APARTADO ESTÁ INCOMPLETO
> > [!todo] #TODO

El **NVM** (*Node Version Manager*) es el gestor de versiones de [**NodeJS**](nodejs.md); este nos permitirá instalar, usar y borrar versiones de [**NodeJS**](nodejs.md) en nuestro equipo.

## INSTALAR VERSIÓN

> [!abstract] SINTAXIS
> nvm install ***\[version\]***

## CAMBIAR DE VERSIÓN

> [!abstract] SINTAXIS
> nvm use ***\[version\]***

## LISTAR VERSIONES INSTALADAS

> [!abstract] SINTAXIS
> nvm ls

> [!abstract] SINTAXIS
> nvm list

## LISTAS VERSIOENS DISPONIBLES PARA INSTALAR

> [!abstract] SINTAXIS
> nvm ls-remote

## DESINSTALAR VERSIONES

> [!abstract] SINTAXIS
> nvm uninstall ***\[version\]***

## VERSIÓN POR DEFECTO

> [!abstract] SINTAXIS
> nvm alias default ***\[version\]***

## VERSIÓN ACTUAL

> [!abstract] SINTAXIS
> nvm current

## VERSION DE NVM

> [!abstract] SINTAXIS
> nvm version

## EJECUTAR COMANDO

> [!abstract] SINTAXIS
> nvm exec ***\[version\] \[command\]***
