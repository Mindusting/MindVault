# BORRAR USUARIOS EN LINUX

Para borrar usuarios en **Linux** se usa el comando `deluser` seguido del nombre identificativo del usuario; ten en cuenta que este comando tiene que tener el prefijo de `sudo` para poder funcionar.

> [!abstract] SINTAXIS
> sudo deluser ***\[username\]***
