> [!info] NOTA TEMPORAL
> Los métodos básicos de un proceso son los siguientes:
> - `destroy()`: Destruye el proceso.
> - `exitValue()`: Devuelve el valor de retorno.
> - `getErrorStream()`: Devuelve el `ErrorStream` del proceso.
> - `getInputStream()`: Devuelve el `InputStream` del proceso.
> - `getOutputStream()`: Devuelve el `OutputStream` del proceso.
> - `isAlive()`: Devuelve un valor booleano indicando si está vivo.
> - `waitFor()`: Detiene la ejecución del proceso padre hasta que termine el hijo.
